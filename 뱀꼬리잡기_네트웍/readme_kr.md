# 스네이크 온라인 (Snake Online)

## 게임 설명
스네이크 온라인은 고전 스네이크 게임을 기반으로 한 멀티플레이어 온라인 게임입니다. 플레이어는 자신만의 뱀을 조종하여 게임 그리드 위에서 먹이를 먹고 몸집을 키워야 합니다. 다른 플레이어의 뱀이나 자신의 몸에 부딪히지 않으면서 가장 길게 살아남거나 특정 목표 길이에 도달하는 것이 목표입니다.

## 게임 특징
*   **멀티플레이어:** 여러 플레이어가 동시에 한 방에서 게임을 즐길 수 있습니다.
*   **로비 시스템:** 사용자 이름으로 로그인하고, 새로운 게임 방을 만들거나 기존 방에 참여할 수 있습니다.
*   **성장 및 점수:** 먹이를 먹으면 뱀의 길이가 길어지고, 뱀의 길이가 곧 점수가 됩니다.
*   **충돌 감지:** 자신의 몸이나 다른 뱀과 충돌하면 게임 오버가 됩니다.
*   **벽 통과:** 화면의 가장자리에 도달하면 반대편에서 다시 나타나는 벽 통과 기능이 있습니다.
*   **승리 조건:** 설정된 목표 길이에 도달하거나, 마지막까지 살아남은 플레이어가 승리합니다.
*   **사운드 효과:** 이동 및 충돌 시 효과음이 재생됩니다.
*   **UI 패널:** 게임 중 플레이어들의 점수와 뱀의 길이를 시각적으로 보여주는 UI 패널이 제공됩니다.

## 게임 규칙
1.  **로그인:** 게임 시작 전 사용자 이름을 입력하여 로그인해야 합니다.
2.  **방 참여/생성:** 로비에서 기존 게임 방에 참여하거나 새로운 방을 생성할 수 있습니다.
3.  **뱀 조종:** 키보드의 방향키 (또는 WASD 키)를 사용하여 뱀의 이동 방향을 변경합니다.
    *   `W` 또는 `↑`: 위로 이동
    *   `A` 또는 `←`: 왼쪽으로 이동
    *   `S` 또는 `↓`: 아래로 이동
    *   `D` 또는 `→`: 오른쪽으로 이동
4.  **먹이 섭취:** 그리드에 나타나는 먹이를 먹으면 뱀의 길이가 길어집니다.
5.  **충돌 회피:** 자신의 뱀 몸통이나 다른 플레이어의 뱀에 부딪히면 게임에서 패배합니다.
6.  **승리:**
    *   가장 먼저 목표 길이(`WIN_LENGTH`)에 도달한 플레이어가 승리합니다.
    *   다른 모든 플레이어가 게임 오버되고 마지막까지 살아남은 플레이어가 승리합니다.
7.  **게임 오버 후:** 게임 오버 화면에서 '로비로 돌아가기' 버튼을 클릭하여 로비로 돌아갈 수 있습니다.

## 시작하는 방법
1.  **서버 실행:** `server` 폴더로 이동하여 `run.bat` 파일을 실행하여 게임 서버를 시작합니다.
2.  **클라이언트 실행:** `client` 폴더로 이동하여 `run.bat` 파일을 실행하여 게임 클라이언트를 시작합니다.
3.  **로그인:** 클라이언트 창에서 사용자 이름을 입력하고 로그인합니다.
4.  **방 선택:** 로비에서 원하는 게임 방에 참여하거나 새로운 방을 생성하여 게임을 시작합니다.
