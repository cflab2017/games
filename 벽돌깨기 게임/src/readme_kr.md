# 파이썬 벽돌깨기 (Breakout)

## 🎮 게임 설명
이 게임은 Pygame 라이브러리를 사용하여 개발된 고전 아케이드 게임 '벽돌깨기'의 파이썬 버전입니다. 플레이어는 화면 하단의 패들을 조작하여 공을 튕겨 상단의 벽돌들을 모두 파괴하는 것이 목표입니다. 다양한 아이템과 레벨 시스템, 화려한 그래픽 효과가 더해져 더욱 몰입감 있는 경험을 제공합니다.

## 🕹️ 제어
*   **왼쪽 화살표 (←):** 패들을 왼쪽으로 이동
*   **오른쪽 화살표 (→):** 패들을 오른쪽으로 이동
*   **스페이스바 (Space):**
    *   게임 시작 (시작 화면에서)
    *   게임 오버 후 재시작
    *   총알 아이템 획득 시 총알 발사

## ✨ 주요 기능
*   **기본 게임 플레이:** 패들, 공, 벽돌을 이용한 고전 벽돌깨기 메커니즘.
*   **점수 시스템:** 벽돌 파괴 시 점수 획득.
*   **생명 시스템:** 공이 화면 하단으로 떨어지면 생명 감소, 0이 되면 게임 오버.
*   **레벨 시스템:** 모든 벽돌 파괴 시 다음 레벨로 진행, 공 속도 증가 및 새로운 벽돌 배열 생성.
*   **아이템 시스템:**
    *   **생명 아이템:** 획득 시 생명 1 증가.
    *   **총알 아이템:** 획득 시 총알 5개 충전, 스페이스바로 발사하여 벽돌 파괴 가능.
*   **객체지향 설계:** `Game`, `Paddle`, `Ball`, `Brick` 등 각 요소를 클래스로 구현하여 유지보수 및 확장 용이.
*   **최적화:** 60 FPS 고정으로 부드러운 게임 플레이.

## 💥 효과
*   **그라데이션 배경:** 시각적으로 부드러운 배경 효과.
*   **3D 입체감:** 패들, 공, 벽돌에 간단한 3D 음영 효과 적용.
*   **충돌 파티클:** 공과 벽돌, 공과 패들, 총알과 벽돌 충돌 시 화려한 파티클 효과.
*   **공 트레일:** 공이 움직이는 경로에 시각적인 꼬리(트레일) 효과.
*   **하단 경계선 효과:** 공이 화면 하단으로 나갈 때 경계선이 붉게 변하는 시각적 피드백.
*   **사운드 효과:** 벽돌 파괴, 패들 충돌, 총알 발사, 아이템 획득 시 적절한 사운드.
*   **가상 키보드 표시:** 게임 화면 우측에 현재 눌린 키를 시각적으로 보여주는 가상 키보드.

## 📁 파일 구조
```
.
├── game.py             # 게임 실행 메인 파일
├── gemini.md           # Gemini AI와의 대화 기록 및 지시사항
├── history.md          # 프로젝트 진행 기록
├── narration.md        # 유튜브 쇼츠용 나레이션/자막
├── readme_kr.md        # (현재 파일) 한국어 README
├── readme_en.md        # 영어 README
├── assets/             # 게임에 사용되는 이미지, 사운드 등 리소스
│   ├── brick_hit.wav
│   ├── bullet.wav
│   ├── item_collect.wav
│   └── paddle_hit.wav
└── src/                # 게임 로직을 구성하는 클래스 파일들
    ├── ball.py         # 공(Ball) 클래스
    ├── brick.py        # 벽돌(Brick) 클래스
    ├── bullet.py       # 총알(Bullet) 클래스
    ├── game.py         # 게임 전체 관리(Game) 클래스 (메인 로직)
    ├── item.py         # 아이템(Item) 클래스
    ├── keyboard.py     # 가상 키보드(Keyboard) 클래스
    ├── paddle.py       # 패들(Paddle) 클래스
    └── particle.py     # 파티클(Particle) 클래스
```

## 📄 파일 설명
*   **`game.py` (루트):** `src/game.py`의 `Game` 클래스를 인스턴스화하고 실행하는 진입점 파일입니다.
*   **`src/game.py`:** 게임의 전체적인 흐름, 초기화, 게임 루프, 충돌 처리, 점수/생명/레벨 관리, 아이템 및 총알 로직 등 핵심 게임 로직을 담당하는 `Game` 클래스를 포함합니다.
*   **`src/paddle.py`:** 플레이어가 조작하는 패들의 속성(크기, 색상, 속도) 및 동작(이동, 그리기)을 정의하는 `Paddle` 클래스입니다.
*   **`src/ball.py`:** 게임 공의 속성(반지름, 색상, 속도) 및 동작(이동, 벽/패들 충돌 처리, 그리기, 트레일 효과)을 정의하는 `Ball` 클래스입니다.
*   **`src/brick.py`:** 게임 내 벽돌의 속성(위치, 크기, 색상) 및 그리기(3D 효과 포함)를 정의하는 `Brick` 클래스입니다.
*   **`src/item.py`:** 벽돌 파괴 시 드롭되는 아이템(생명, 총알)의 속성 및 동작을 정의하는 `Item` 클래스입니다.
*   **`src/bullet.py`:** 총알 아이템 획득 후 발사되는 총알의 속성 및 동작을 정의하는 `Bullet` 클래스입니다.
*   **`src/particle.py`:** 충돌 및 기타 시각 효과를 위한 파티클의 속성 및 동작을 정의하는 `Particle` 클래스입니다.
*   **`src/keyboard.py`:** 화면에 가상 키보드를 표시하고 키 입력 이벤트를 처리하는 `Keyboard` 클래스입니다.
*   **`assets/`:** 게임에 사용되는 모든 사운드 파일(`brick_hit.wav`, `bullet.wav`, `item_collect.wav`, `paddle_hit.wav`)이 저장된 폴더입니다.
